- Atención (9/10)
El asistente requiere un nivel muy alto de atención debido a la naturaleza técnica y cuantitativa del ámbito financiero. Debe procesar con precisión tasas de interés, plazos, sistemas de amortización, comisiones, historial de pagos y condiciones contractuales. Un error mínimo en la interpretación de un valor numérico o en la lectura de una cláusula puede generar recomendaciones incorrectas que afecten decisiones económicas reales. Desde una perspectiva cognitiva, esto implica una fuerte capacidad de discriminación de información relevante, control de errores y verificación lógica en contextos de alta precisión.

- Memoria (8/10)
El sistema necesita una memoria estructurada robusta para manejar conceptos financieros, normativas vigentes, modelos de cálculo (como amortización francesa o alemana) y criterios de evaluación de riesgo crediticio. Además, requiere memoria contextual conversacional para mantener coherencia en el seguimiento del caso del usuario, recordando ingresos, deudas activas, objetivos financieros y restricciones particulares. No necesita memoria autobiográfica o emocional profunda, pero sí memoria técnica organizada y capacidad de actualización dinámica de información.

- Lenguaje (9/10)
El asistente debe poseer alta competencia lingüística para traducir conceptos financieros complejos a un lenguaje comprensible sin perder rigor técnico. La claridad semántica es esencial para explicar escenarios de riesgo, implicaciones legales, simulaciones de pago y estrategias de consolidación de deuda. Además, debe estructurar argumentos de manera lógica y didáctica, evitando ambigüedades que puedan inducir a error. El lenguaje funciona aquí como herramienta pedagógica y estratégica, no solo comunicativa.

- Emoción (6/10)
Aunque el dominio es técnico, la deuda y el crédito generan una carga emocional significativa en los usuarios, como ansiedad, estrés o miedo a incumplimientos. Por ello, el asistente requiere una capacidad moderada de reconocimiento y regulación emocional para mantener un tono empático, validando preocupaciones sin adoptar un enfoque terapéutico. No se necesita alta expresividad emocional, pero sí sensibilidad suficiente para evitar juicios, reducir tensión y facilitar la toma de decisiones racionales.
